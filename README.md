# Web3Bridge Cohort XIV - Solidity Projects

This repository contains all the projects I completed during my Solidity class at Web3Bridge Cohort XIV.

## About

Web3Bridge is a blockchain development training program that focuses on building practical skills in smart contract development and decentralized applications. This collection represents my learning journey and hands on experience with Solidity and blockchain technology.

## Repository Structure

This folder organizes all projects developed throughout the cohort, showcasing progress from foundational concepts to more advanced implementations.

## Technologies Used

- Solidity
- Ethereum
- Smart Contract Development Tools

## Cohort Information

- **Program**: Web3Bridge
- **Cohort**: XIV (14)
- **Focus**: Solidity Smart Contract Development

## Learning Outcomes
- Implemented algorithm fundamentals in JavaScript (Euclidean GCD).
- Built a Caesar Cipher React app with encrypt/decrypt flows and ASCII-based shifting.
- Practiced Hardhat and Foundry setup with simple contracts (`Greeter`, `Owner`) and deployment/testing scripts.
- Built core Solidity patterns with structs, arrays, mappings, and CRUD (`Todo`).
- Implemented custom ERC20 tokens with transfer, allowance, and approval logic.
- Built savings contracts for ETH and ERC20 deposits/withdrawals (`SaveEther`, `SaveAsset`).
- Designed a school management/payment system with staff/student workflows, fees, and salary intervals (`Chlorine`).
- Implemented a tokenized property marketplace using ERC20 payments (`LitiumToken`, `AtomProperties`).
- Built NFTs with per-token URIs and fully on-chain metadata/mood switching (`YujiNFT`, `MoodNft`).
- Integrated Uniswap V2 router flows for swaps and liquidity provisioning (`UseSwap`).
- Built a multisig wallet and factory with confirmation flow and signer onboarding (`MultiSig`, `MultiSigFactory`).
- Used deterministic deployments with `CREATE2` (`NumberFactory`).
- Built the Vaultiks system: deterministic token vaults, NFT receipts, dynamic SVG metadata, and Foundry tests (`VaultFactory`, `TokenVault`, `VaultNFT`, `SVGRenderer`).
- Expanded frontend skills with React/Vite projects, including a todo app and a school management UI using Web3Auth, AppKit, and ethers.
